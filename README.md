# 📄 pdfjin-pdf-to-powerpoint

> Convert PDF presentations into editable PowerPoint slides (PPTX) by PDFJin by [PDFJin](https://pdfjin.com).

[![PyPI version](https://img.shields.io/pypi/v/pdfjin-pdf-to-powerpoint.svg)](https://pypi.org/project/pdfjin-pdf-to-powerpoint/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Python 3.8+](https://img.shields.io/badge/python-3.8+-blue.svg)](https://www.python.org/downloads/)

Fast, private, and local document processing with zero size limits.

> 🌐 **Prefer a Web UI?** Use the free online browser tool at **[https://pdfjin.com/pages/pdf-to-powerpoint.html](https://pdfjin.com/pages/pdf-to-powerpoint.html)**.

---

## 📦 Installation

```bash
pip install pdfjin-pdf-to-powerpoint
```

Or install from source:

```bash
git clone https://github.com/pdfjin/pdfjin-pdf-to-powerpoint.git
cd pdfjin-pdf-to-powerpoint
pip install .
```

---

## 🚀 Quickstart

Run via CLI:
```bash
pdfjin-pdf-to-powerpoint --help
```

Use in Python:
```python
import pdfjin_pdf_to_powerpoint
```
